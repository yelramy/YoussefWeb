# OrbitDesk

OrbitDesk is a concept landing page for an operations hub built for studios and independent founders who want calm, intentional weeks.

## Stack
- Next.js 14 (App Router)
- TypeScript + Tailwind CSS
- lucide-react icon set

## Structure
- `app/layout.tsx` defines the base font stack and metadata
- `app/page.tsx` renders the entire single-page marketing experience
- `app/globals.css` sets minimal theming helpers for the glassmorphic UI

## Development
Install dependencies and start the dev server:

```bash
npm install
npm run dev
```

The page is static—no environment variables or backend services are required.
