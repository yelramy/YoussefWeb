# Echolume Studio

Echolume Studio is a concept interior-ritual practice built with Next.js 14 and Tailwind CSS. The single-page experience walks visitors through immersive rituals, atmospheric palettes, and a residency waitlist for multi-sensory home transformations.

## Stack

- **Next.js 14 / React 18** for the App Router experience
- **TypeScript** for type safety
- **Tailwind CSS** for expressive theming
- **Lucide Icons** for glyphs that reinforce the ritual storytelling

## Getting started

```bash
npm install
npm run dev
```

The development server runs on [http://localhost:3000](http://localhost:3000).
